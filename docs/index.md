## Installation

Simply pip-installing the package in place (using traditional pip or uv) will work.

=== "pip"
    ```bash
    git clone git@github.com:jmag722/minuteman.git
    cd minuteman
    python -m venv .venv
    source .venv/bin/activate
    pip install .
    ```
=== "uv"
    ```bash
    git clone git@github.com:jmag722/minuteman.git
    cd minuteman
    uv venv
    source .venv/bin/activate
    uv pip install .
    ```
